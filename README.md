# Sân tập lùi xe

Game mô phỏng lái xe nhìn từ trên xuống, gồm ghép ngang, ghép dọc và hình chữ chi xuôi/ngược. Mở `index.html` trong trình duyệt để chơi.

- **W/S** hoặc **↑/↓** để tiến/lùi.
- **A/D** hoặc **←/→** để đánh lái.
- **G** để trả lái, **Space** để phanh, **Esc** để tập lại.
- Bật **Quỹ đạo** để xem đường giữa và hai vệt bánh.
